# BunArmyMonitor
BunArmyMonitor is a remote monitoring and management solution comprising two software packages: a Master (main server with interface) and an Agent (installed on Windows or Linux client machines).

The Master provides an intuitive dashboard for :

- Monitor the health of workstations (system statistics, online status, etc.)

- Schedule or execute remote actions (Windows update, executing commands, application deployment, reboot, shutdown, etc.)

- EZ Connect to machines via MSTSC or other integrated tools.

BunArmyMonitor is designed to facilitate the centralized and efficient administration of multiple PCs.
